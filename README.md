## 💡 О проекте

Официальное приложение `eSchool` («Электронная школа», разработчик ООО «ИТ-Стратегия») давно страдает от устаревшего дизайна, тяжеловесности, отсутствия нормального офлайн-режима и долгой подгрузки каждого экрана.

**YouSchool** — это независимая альтернатива с открытым исходным кодом, написанная с нуля на современном стеке Android для максимального комфорта школьников и родителей.

## ✨ Основные возможности

### ⚡ Offline-First и мгновенный запуск
* **Мгновенное открытие за 0 мс**: расписание, оценки и домашние задания сохраняются в локальной базе данных **Room (SQLite)**. Приложение мгновенно запускается в лифте, метро или в кабинетах без связи.
* **Очередь отложенной синхронизации**: отметки выполнения домашних заданий и загрузка файлов решений сохраняются локально и автоматически отправляются на сервер eSchool в фоне при появлении интернета.
* **Индикатор подключения**: ненавязчивый статус-баннер при переходе в офлайн-режим.

### 📅 Умное расписание
* **Интерактивная карусель дней**: плавная смена дней свайпами (`HorizontalPager`) с быстрым переходом к сегодняшнему дню в один тап.
* **Оценки на уроке**: цветные бейджи оценок прямо в расписании с верхним индексом веса (например, 5¹·⁵). При нажатии на бейдж открывается карточка с полными деталями (тип работы, преподаватель, дата выставления).

### 📊 Продвинутая аналитика оценок и калькулятор «Что если»
* **Средневзвешенный балл**: автоматический расчёт честного балла с учётом официальных весов каждой работы eSchool.
* **Калькулятор-симулятор балла**:
  * Добавление гипотетических оценок с любым весом (1.0, 1.5, 2.0 и др.) для прогнозирования четвертного балла.
  * Исключение существующих оценок из расчёта (режим зачёркивания).
  * Живой пересчёт и визуализация того, как изменится итоговая оценка.
* **Блок «Новые оценки»**: компактные карточки недавно выставленных отметок вверху экрана с возможностью быстро отметить их прочитанными.
* **Защита от спама**: при первом входе старые исторические оценки автоматически помечаются прочитанными — отображаются только те оценки, которые учитель выставил уже после установки приложения.

### ✅ Домашние задания и вложения
* **Интерактивные чекбоксы**: быстрое переключение готовности ДЗ с сохранением состояния на сервере и локально.
* **Просмотр вложений**: встроенный просмотрщик файлов домашнего задания (PDF, изображения, документы).
* **Сдача работ**: прикрепление и удаление файлов с выполненным домашним заданием прямо из карточки урока.

### 💬 Сообщения eSchool
* **Полноценный встроенный чат**: личные диалоги с учителями и одноклассниками, групповые рассылки и системные уведомления.
* **Markdown-форматирование**: корректный рендеринг текста с сохранением абзацев и переносов строк.

### 🎨 Персонализация и дизайн Material You
* **Динамические цвета (Monet)**: палитра интерфейса автоматически адаптируется под системные обои устройства (Android 12+).
* **Темы оформления**: Светлая, Тёмная, глубокий чёрный **AMOLED** и адаптивная системная палитра.
* **Кастомизация нижней панели**:
  * Выбор стиля: классический системный док или плавающая полупрозрачная капсула с жестовым перемещением индикатора 1:1 за пальцем.
  * Настройка вкладок: выбор от 2 до 5 активных пунктов с перетаскиванием (drag-and-drop), пружинной анимацией привязки к слотам и тактильным откликом.
* **Онбординг**: интерактивный мастер первичной настройки темы, палитры и навигации при первом запуске.

### 🔔 Уведомления и безопасность
* **Фоновые проверки (`WorkManager`)**: тихие периодические проверки журнала и уведомления о реально новых оценках.
* **Напоминания о ДЗ**: настраиваемое по времени напоминание о невыполненных уроках в день сдачи.
* **Безопасность**: учётные данные и токены сессий шифруются с помощью **EncryptedSharedPreferences** и **Android Keystore**; пароли передаются только в виде криптографического SHA-256 хэша.

## 🛠 Технологический стек

* **Язык**: Kotlin 2.0
* **UI**: Jetpack Compose + Material 3 (Material You)
* **Архитектура**: MVVM, Clean Architecture, Offline-First
* **База данных**: Room Database (SQLite) + Kotlin Flow
* **Сеть**: OkHttp 4 + Kotlinx.Serialization
* **Фоновые задачи**: AndroidX WorkManager
* **Безопасность**: AndroidX Security Crypto (MasterKeys, EncryptedSharedPreferences)

## 🚀 Сборка проекта

### Требования
* JDK 17+
* Android SDK (API 35, Build-Tools 35+)

### Команды Gradle
```bash
# Запуск модульных тестов
./gradlew testDebugUnitTest

# Сборка Debug APK
./gradlew assembleDebug

# Сборка Release APK
./gradlew assembleRelease
```

Собранные установочные пакеты:
* **Debug APK**: `app/build/outputs/apk/debug/youschool_<versionName>.apk`
* **Release APK**: `app/build/outputs/apk/release/youschool_<versionName>.apk`
